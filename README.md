## 🌟 প্রজেক্টের পরিচিতি (Overview)

**Royal Noor (রয়েল নূর)** হলো একটি সম্পূর্ণ স্বয়ংক্রিয় ইসলামিক কার্ড জেনারেশন প্ল্যাটফর্ম। এটি প্রতিদিন পবিত্র কোরআনের আয়াত, সহীহ হাদিস ও অনুপ্রেরণামূলক ইসলামিক নসিহত থেকে স্মার্ট রোটেশনের মাধ্যমে বাণী নির্বাচন করে চমৎকার **১০৮০×১০৮০ পিক্সেল** সোশ্যাল মিডিয়া পোস্ট কার্ড তৈরি করে। 

এটি ফেসবুক, ইনস্টাগ্রাম, হোয়াটসঅ্যাপ স্ট্যাটাস ও অন্যান্য সোশ্যাল মিডিয়ায় সরাসরি পোস্ট করার জন্য প্রস্তুত ক্যাপশন ও মেটাডাটা সহ `today.png` এবং `today.json` আউটপুট দেয়।

## ✨ মূল সুবিধাসমূহ (Key Features)

* 🕌 **ক্যালেন্ডার ও ইভেন্ট-বেসড এ্যাসাইনমেন্ট ইঞ্জিন:**
  - **রমজানুল মোবারক স্পেশাল:** মাহে রমজানের পুরো ৩০ দিন স্বয়ংক্রিয়ভাবে সিয়াম, তারাবীহ, কদর ও তাকওয়া সংক্রান্ত বাণী প্রকাশিত হবে।
  - **জুমু'আ স্পেশাল:** প্রতি শুক্রবার অগ্রাধিকার ভিত্তিতে জুমার ফজিলত, সূরা আল-কাহাফ ও দুরুদ শরীফের হাদিস পোস্ট হবে।
  - **জিলহজ্জ ও অন্যান্য দিন:** কুরবানী, হজ ও সাধারণ দিনগুলোতে ধৈর্য, কৃতজ্ঞতা, নিয়ত ও উত্তম চরিত্রের বাণী সমভাবে চক্রাকারে আসবে।
* 🗄️ **SQLite ডাটাবেজ ও স্মার্ট রোটেশন:**
  - ডাটাবেজে প্রতিটি বাণীর ব্যবহারের সংখ্যা (`used_count`) ও শেষ ব্যবহারের সময় (`last_used_at`) ট্র্যাক রাখা হয়, ফলে কোনো বাণী ঘন ঘন পুনরাবৃত্তি হয় না।
* 🎨 **৪টি প্রিমিয়াম রয়েল থিম (১০৮০×১০৮০ ক্যানভাস):**
  - **Royal Emerald:** গভীর পান্না সবুজ + স্বর্ণালী বর্ডার ও ক্যালিগ্রাফি।
  - **Midnight Navy:** গভীর নীল + গোল্ডেন অ্যাকসেন্ট।
  - **Imperial Black:** লাক্সারি ম্যাট ব্ল্যাক + মেটালিক গোল্ড টেক্সট।
  - **Warm Parchment:** ক্ল্যাসিক হস্তলিখিত পাণ্ডুলিপির টেক্সচার ও ফ্রেম।
* 🔤 **নিখুঁত আরবি ও বাংলা টাইপোগ্রাফি:**
  - অফলাইনে ও গিটহাবে নির্ভুল হরকত ও ফন্ট প্রদর্শনের জন্য **Amiri** (আরবি) এবং **Hind Siliguri** (বাংলা) ফন্ট সংকলিত।
* 🛡️ **গিটহাব ৬০-দিনের ল্যাপস প্রিভেনশন (Keepalive Engine):**
  - গিটহাবের নিয়ম অনুযায়ী ৬০ দিন নিষ্ক্রিয় থাকলে ক্রন শিডিউলার বন্ধ হয়ে যায়। রয়েল নূরে প্রতিদিনের অটো-কমিট ছাড়াও একটি ব্যাকআপ `keepalive.yml` রয়েছে যা প্রতি সপ্তাহে চেক করে ৬০ দিনের টাইমার স্বয়ংক্রিয়ভাবে রিসেট করে দেয়।
* 🌐 **মডার্ন ওয়েব ইন্টারফেস (`index.html`):**
  - তাৎক্ষণিক লাইভ সার্চ ও বিষয়ভিত্তিক ফিল্টারিং।
  - প্রতিটি বাণীর আরবি ও বাংলা এক ক্লিকে কপি করার সুবিধা।
  - যেকোনো বাণীর ১০৮০×১০৮০ ক্যানভাস প্রিভিউ ও সরাসরি ডাউনলোড।
  - ব্রাউজার থেকেই নতুন বাণী যুক্ত ও JSON এক্সপোর্ট করার সহজ ব্যবস্থা।

## 🚀 লোকাল রান ও কমান্ডসমূহ (Commands)

### ১. লোকাল অ্যাডমিন ড্যাশবোর্ড ওপেন করা:
```bash
npm run admin
```
> এটি ব্রাউজারে `http://localhost:3300/admin.html` ওপেন করবে। এখান থেকে আপনি সরাসরি SQLite ডাটাবেজে নতুন আয়াত বা হাদিস যুক্ত করতে ও ডিলিট করতে পারবেন।

### ২. আজকের কার্ড জেনারেট করা:
```bash
npm run generate
```

### ৩. ডাটাবেজ ইনিশিয়ালাইজ / রিসেট:
```bash
npm run init-db
```

## 📥 নতুন আয়াত বা হাদিস যুক্ত করার নিয়ম

গিটহাব বা লাইভ ওয়েব থেকে বহিরাগত কেউ ডাটাবেজ পরিবর্তন করতে পারবে না। শুধুমাত্র আপনি আপনার লোকালহোস্ট থেকে ডাটা যুক্ত করতে পারবেন:

### পদ্ধতি ১: লোকাল অ্যাডমিন প্যানেল থেকে (সবচেয়ে সহজ)
1. টার্মিনালে রান করুন:
   ```bash
   npm run admin
   ```
   (অথবা লারাগনে সরাসরি `http://localhost/Github/Royal%20Noor/admin.html` ওপেন করুন)
2. সুন্দর ফর্মে নতুন হাদিস বা আয়াতের আরবি, বাংলা ও তথ্য দিয়ে **"সংরক্ষণ করুন"** চাপুন।
3. সরাসরি আপনার লোকাল SQLite ডাটাবেজে যুক্ত হয়ে যাবে!

### পদ্ধতি ২: বাল্ক JSON ইমপোর্ট
1. `database/imports.json` ফাইলে নতুন আয়াত বা হাদিসের অ্যারে পেস্ট করুন:
   ```json
   [
     {
       "type": "quran",
       "title": "সূরা আল-ইমরান",
       "reference": "সূরা আল-ইমরান : ১৩৯",
       "arabic_text": "وَلَا تَهِنُوا وَلَا تَحْزَنُوا وَأَنتُمُ الْأَعْلَوْنَ إِن كُنتُم مُّؤْمِنِينَ",
       "bangla_translation": "তোমরা হতাশ হয়ো না এবং দুঃখ করো না। তোমরাই বিজয়ী হবে, যদি তোমরা প্রকৃত মুমিন হও।",
       "category": "ধৈর্য ও বিজয়",
       "event_tag": "general"
     }
   ]
   ```
2. টার্মিনালে রান করুন:
   ```bash
   npm run import
   ```

## 🤖 সোশ্যাল মিডিয়া অটোমেশন (Make.com / Webhook)

প্রতিদিন জেনারেট হওয়া `cards/today.json` ফাইলটিতে সোশ্যাল মিডিয়ার জন্য সম্পূর্ণ প্রস্তুত করা ক্যাপশন ও ছবির লিঙ্ক থাকে:
```json
{
  "cardId": "RN-20261105-OQAP",
  "title": "সূরা আল-বাকারা",
  "reference": "সূরা আল-বাকারা : ১৫২",
  "caption": "✨ আজকের নূর | Royal Noor — আলোর পথে প্রতিদিন\n\nفَاذْكُرُونِي أَذْكُرْكُمْ وَاشْكُرُوا لِي وَلَا تَكْفُرُونِ\n\n❝ অতএব তোমরা আমাকে স্মরণ কর, আমিও তোমাদেরকে স্মরণ করব। আর তোমরা আমার প্রতি কৃতজ্ঞ হও এবং অকৃতজ্ঞ হয়ো না। ❞\n— [ সূরা আল-বাকারা : ১৫২ ]\n\n🌐 ওয়েবসাইট: https://www.royaltechbd.com/\n🏷️ নিবেদনে: Royal Technologies",
  "imageUrl": "https://royal-technologies.github.io/Royal-Noor/cards/today.png"
}
```
এটি Make.com বা Zapier দিয়ে স্বয়ংক্রিয়ভাবে ফেসবুক পেজ বা ইনস্টাগ্রামে পোস্ট করা যায়।
