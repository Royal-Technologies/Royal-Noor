## 🌟 প্রজেক্টের পরিচিতি (Overview)

**Royal Noor (রয়েল নূর)** হলো একটি সম্পূর্ণ স্বয়ংক্রিয় ইসলামিক কার্ড জেনারেশন প্ল্যাটফর্ম। এটি প্রতিদিন পবিত্র কোরআনের আয়াত, সহীহ হাদিস ও অনুপ্রেরণামূলক ইসলামিক নসিহত থেকে স্মার্ট রোটেশনের মাধ্যমে বাণী নির্বাচন করে চমৎকার **১০৮০×১০৮০ পিক্সেল** সোশ্যাল মিডিয়া পোস্ট কার্ড তৈরি করে। 

* 🌐 **লাইভ ওয়েব ডিরেক্টরি:** [https://royal-technologies.github.io/Royal-Noor/](https://royal-technologies.github.io/Royal-Noor/)
* 🏷️ **প্রতিষ্ঠাতা ও কারিগরি সহায়তা:** [Royal Technologies](https://www.royaltechbd.com/)

এটি ফেসবুক, ইনস্টাগ্রাম, হোয়াটসঅ্যাপ স্ট্যাটাস ও অন্যান্য সোশ্যাল মিডিয়ায় সরাসরি পোস্ট করার জন্য প্রস্তুত ক্যাপশন ও মেটাডাটা সহ `today.png` এবং `today.json` আউটপুট দেয়।

## ✨ মূল সুবিধাসমূহ (Key Features)

* 🕌 **ক্যালেন্ডার ও ইভেন্ট-বেসড এ্যাসাইনমেন্ট ইঞ্জিন:**
  - **রমজানুল মোবারক স্পেশাল:** মাহে রমজানের পুরো ৩০ দিন স্বয়ংক্রিয়ভাবে সিয়াম, তারাবীহ, কদর ও তাকওয়া সংক্রান্ত বাণী প্রকাশিত হবে।
  - **জুমু'আ স্পেশাল:** প্রতি শুক্রবার অগ্রাধিকার ভিত্তিতে জুমার ফজিলত, সূরা আল-কাহাফ ও দুরুদ শরীফের হাদিস পোস্ট হবে।
  - **জিলহজ্জ ও অন্যান্য দিন:** কুরবানী, হজ ও সাধারণ দিনগুলোতে ধৈর্য, কৃতজ্ঞতা, নিয়ত ও উত্তম চরিত্রের বাণী সমভাবে চক্রাকারে আসবে।
* 🗄️ **SQLite ডাটাবেজ ও স্মার্ট রোটেশন (৪০০টি বাণী):**
  - ২০০টি বাছাইকৃত ছোট ও অর্থবহ পবিত্র কোরআনের আয়াত।
  - ২০০টি সহীহ হাদিস সংকলন।
  - ডাটাবেজে প্রতিটি বাণীর ব্যবহারের সংখ্যা (`used_count`) ও শেষ ব্যবহারের সময় (`last_used_at`) ট্র্যাক রাখা হয়, ফলে কোনো বাণী ঘন ঘন পুনরাবৃত্তি হয় না।
* 🎨 **১০টি প্রিমিয়াম রয়েল থিম (সিরিয়াল রোটেশন):**
  - **Royal Emerald:** গভীর পান্না সবুজ + স্বর্ণালী বর্ডার ও ক্যালিগ্রাফি।
  - **Midnight Navy:** গভীর নীলকান্ত + গোল্ডেন অ্যাকসেন্ট।
  - **Imperial Black:** কাবার গিলাফ অনুপ্রাণিত কালো মার্বেল ও উজ্জ্বল সোনা।
  - **Warm Parchment:** ক্ল্যাসিক হস্তলিখিত মদিনা পাণ্ডুলিপির ভিন্টেজ আর্ট (লাইট থিম)।
  - **Royal Maroon:** দামেস্ক ভেলভেট লাল ও উজ্জ্বল অ্যান্টিক গোল্ড।
  - **Ottoman Turquoise:** ব্লু মস্ক ও তোপকাপি প্রাসাদের রাজকীয় ফিরোজা টাইলস।
  - **Desert Amber:** আরব্য মরুভূমি সূর্যাস্ত, অ্যাম্বার ও জাফরান স্বর্ণ।
  - **Amethyst Violet:** আত্মিক প্রশান্তিময় বেগুনি ও শ্যাম্পেন গোল্ড।
  - **Andalusian Mihrab:** আন্দালুসীয় কর্ডোবা মেহরাব আর্চ স্থাপত্যের নকশা।
  - **Classic Ivory:** শুভ্র আইভরি পেপার ও চারকোল সোনা (মডার্ন লাইট থিম)।
* 🔤 **নিখুঁত আরবি ও বাংলা টাইপোগ্রাফি (জিরো গ্লিফ বক্স):**
  - খাঁটি ক্যানভাস ভেক্টর জ্যামিতি (`drawIslamicStar`, `drawCrescentMoon`, `drawVectorQuote`) ব্যবহারের কারণে কোনো ডিভাইসে গ্লিফ বা বক্স (`□`) আসার সুযোগ নেই।
  - হরকত ও ফন্ট প্রদর্শনের জন্য **Amiri** (আরবি) এবং **Hind Siliguri** (বাংলা) ফন্ট সংকলিত।
* 📤 **সোশ্যাল শেয়ার ইঞ্জিন (Direct Card Share):**
  - মোবাইল ও অ্যাপসে সরাসরি কার্ড ইমেজ শেয়ারিং (Web Share API)।
  - ডেস্কটপে এক ক্লিকে ক্লিপবোর্ডে ইমেজ কপি (ফেসবুক/হোয়াটসঅ্যাপে `Ctrl+V` পেস্টের জন্য)।
* 🛡️ **গিটহাব ৬০-দিনের ল্যাপস প্রিভেনশন (Keepalive Engine):**
  - গিটহাবের নিয়ম অনুযায়ী ৬০ দিন নিষ্ক্রিয় থাকলে ক্রন শিডিউলার বন্ধ হয়ে যায়। রয়েল নূরে প্রতিদিনের অটো-কমিট ছাড়াও একটি ব্যাকআপ `keepalive.yml` রয়েছে যা প্রতি সপ্তাহে চেক করে ৬০ দিনের টাইমার স্বয়ংক্রিয়ভাবে রিসেট করে দেয়।
* 🌐 **মডার্ন ওয়েব ইন্টারফেস (`index.html`):**
  - তাৎক্ষণিক লাইভ সার্চ ও বিষয়ভিত্তিক ফিল্টারিং (রেসপনসিভ মাল্টি-লাইন)।
  - ডার্ক ও লাইট মোড টগল (আই-ফ্রেন্ডলি কন্ট্রাস্ট)।
  - প্রতিটি বাণীর আরবি ও বাংলা এক ক্লিকে কপি করার সুবিধা।
  - যেকোনো বাণীর ১০৮০×১০৮০ ক্যানভাস প্রিভিউ ও সরাসরি ডাউনলোড।

## 🚀 লোকাল রান ও কমান্ডসমূহ (Commands)

### ১. লোকাল অ্যাডমিন ড্যাশবোর্ড ওপেন করা:
```bash
npm run admin
```
> এটি ব্রাউজারে `http://localhost:3300/admin.html` ওপেন করবে। এখান থেকে আপনি সরাসরি SQLite ডাটাবেজে নতুন আয়াত বা হাদিস যুক্ত করতে ও ডিলিট করতে পারবেন।

### ২. আজকের কার্ড জেনারেট করা:
```bash
npm run generate
```

### ৩. ডাটাবেজ ইনিশিয়ালাইজ / রিসেট:
```bash
npm run init-db
```

## 📥 নতুন আয়াত বা হাদিস যুক্ত করার নিয়ম

গিটহাব বা লাইভ ওয়েব থেকে বহিরাগত কেউ ডাটাবেজ পরিবর্তন করতে পারবে না। শুধুমাত্র আপনি আপনার লোকালহোস্ট থেকে ডাটা যুক্ত করতে পারবেন:

### পদ্ধতি ১: লোকাল অ্যাডমিন প্যানেল থেকে (সবচেয়ে সহজ)
1. টার্মিনালে রান করুন:
   ```bash
   npm run admin
   ```
   (অথবা লারাগনে সরাসরি `http://localhost/Github/Royal%20Noor/admin.html` ওপেন করুন)
2. সুন্দর ফর্মে নতুন হাদিস বা আয়াতের আরবি, বাংলা ও তথ্য দিয়ে **"সংরক্ষণ করুন"** চাপুন।
3. সরাসরি আপনার লোকাল SQLite ডাটাবেজে যুক্ত হয়ে যাবে!

### পদ্ধতি ২: বাল্ক JSON ইমপোর্ট
1. `database/imports.json` ফাইলে নতুন আয়াত বা হাদিসের অ্যারে পেস্ট করুন:
   ```json
   [
     {
       "type": "quran",
       "title": "সূরা আল-ইমরান",
       "reference": "সূরা আল-ইমরান : ১৩৯",
       "arabic_text": "وَلَا تَهِنُوا وَلَا تَحْزَنُوا وَأَنتُمُ الْأَعْلَوْنَ إِن كُنتُم مُّؤْمِنِينَ",
       "bangla_translation": "তোমরা হতাশ হয়ো না এবং দুঃখ করো না। তোমরাই বিজয়ী হবে, যদি তোমরা প্রকৃত মুমিন হও।",
       "category": "ধৈর্য ও বিজয়",
       "event_tag": "general"
     }
   ]
   ```
2. টার্মিনালে রান করুন:
   ```bash
   npm run import
   ```

### 🛠️ অটোমেশন বাস্তবায়নের উপায়সমূহ (How to Set Up)

#### পদ্ধতি ১: Make.com / Zapier দিয়ে (No-Code, সবচেয়ে সহজ)
1. **Trigger:** `HTTP / Webhook` বা `Schedule` মডিউল ব্যবহার করে প্রতিদিন সকাল ০৭:৫০ এবং রাত ০৭:৫০-এ `https://raw.githubusercontent.com/Royal-Technologies/Royal-Noor/main/cards/today.json` থেকে JSON ফেচ করুন।
2. **Action:** Facebook Pages / Instagram Business / Telegram / Buffer মডিউল যুক্ত করুন:
   - **Photo URL:** `{{data.imageUrl}}`
   - **Caption:** `{{data.caption}}`
3. সেভ করে সক্রিয় করে দিন। ব্যস! প্রতিদিন নির্ধারিত সময়ে স্বয়ংক্রিয় পোস্ট হতে থাকবে।

#### পদ্ধতি ২: পাইথন স্ক্রিপ্ট / ক্রনজব দিয়ে (Python Auto-Poster)
```python
import requests

# ১. আজকের ক্যাপশন ও ইমেজ ফেচ
res = requests.get("https://raw.githubusercontent.com/Royal-Technologies/Royal-Noor/main/cards/today.json")
data = res.json()

caption = data["caption"]
image_url = data["imageUrl"]

# ২. ফেসবুক পেজে অটো-পোস্ট (Facebook Graph API)
page_id = "YOUR_PAGE_ID"
access_token = "YOUR_PAGE_ACCESS_TOKEN"

post_url = f"https://graph.facebook.com/v20.0/{page_id}/photos"
payload = {
    "url": image_url,
    "message": caption,
    "access_token": access_token
}
response = requests.post(post_url, data=payload)
print("Facebook Post Response:", response.json())
```
